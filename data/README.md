# Data

This folder contains the TKH export provided by Constructor Knowledge Labs.
The data files are not redistributed.

To reproduce the results, place the following files here:

- `tkh_collection10.json` — the main TKH export (nodes + hyperedges)
- `questions.csv` — 17-question extrinsic benchmark
- `ground_truth.json` — expected methods per question
- `collection10_articles.csv` — source paper metadata
